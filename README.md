# Game test (host)

A short online test of a game in development. One person hosts and the others join with a code.
The download is locked with a password. You will be sent the password separately.

## Before you start (one time)

You need the free program **7-Zip** to open the locked file.
1. Go to https://www.7-zip.org and download the 64-bit Windows version (the first link in the table). Install it.

## Host the game

1. Download **both** files, **host-package-1-of-2.zip** and **host-package-2-of-2.zip** (click each, then the Download button on the right). Put them together in one empty folder. (There are two because the game is too big for one file here.)
2. Right-click **host-package-1-of-2.zip**, choose **7-Zip > Extract here**, and type the password when asked. Then do the same with **host-package-2-of-2.zip**. Both go into the same folder.
3. Open the folder it made and read **START_HERE_HOST.txt**. It has the steps.
4. Keep all the files in that folder together. Double-click **ImpactZeroDays.exe** to start.
   If Windows says it protected your PC, click **More info** then **Run anyway**. If it asks about the firewall, click **Allow access**.
5. Click **Host an online game (friends anywhere)**, and give us the 5-character game code that appears.

You do not need to open anything on your router. The game uses the internet connection you already have.
