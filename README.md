# Performance test

This is a short test of a game in development. It runs by itself for about 5 minutes (Windows only) and writes one small text file.
The file is locked with a password. You will be sent the password separately.

## Before you start (one time)

You need the free program **7-Zip** to open the locked file.
1. Go to https://www.7-zip.org and download the 64-bit Windows version (the first link in the table). Install it.

## Run the test

1. Download **performance-test.7z** from this page (click it, then the Download button on the right).
2. Right-click the downloaded file, choose **7-Zip > Extract here**, and type the password when asked.
3. Close other programs, especially web browsers.
4. Double-click **RunPerformanceTest.bat**. If Windows says it protected your PC, click **More info** then **Run anyway**.
5. The game opens and moves around on its own. **Do not touch the keyboard or mouse.** It takes about 5 minutes and closes itself.
6. Send back the file in the same folder whose name starts with **perf_report** (it ends in .txt).

The test changes nothing on your computer except writing the report file, and it does not use the internet.
